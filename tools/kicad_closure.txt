# The KiCad files vendored into vendor/kicad/ (paths relative to the KiCad
# source root). tools/update_kicad.sh copies exactly these, byte for byte,
# from the release tag it is given. The list is the build's closure: the
# router core (pcbnew/router minus the GUI tool, the board interface and the
# preview items), the kimath/core/include headers and the kimath + Clipper2
# translation units it reaches, measured from the compiler's dependency files
# and the linker's undefined symbols. Everything else the router includes is a
# stand-in under shim/include/ (SOURCE.md lists them).
#
# A new release that includes a file not listed here fails to build with
# "'<path>' file not found": add the path here (if it is KiCad code the
# router needs) or add a stand-in under shim/include/ (if it drags in the
# board model, wxWidgets or the GUI), then run the update again.
