typmax-router · live demo

It draws the wires on a circuit board for you.

A circuit board is a flat card with small metal pads. Each wire must join two pads without touching any other wire. The planning is done by KiCad's own router, taken out of the editor and run as a program other software can call, one wire at a time. Everything below is a replay of the real program's answers on its test boards.

STEP 1
You send the board
A text file listing every pad, every existing wire, and the spacing rules (how far wires must stay apart).
STEP 2
You ask for one wire
"Connect pad U1.1 to pad U2.1." You can also ask it to nudge an existing wire, or to go through to the other side of the board.
STEP 3
It answers with a proposal
Which old wires to take out and which new ones to lay down. Nothing changes on the board until you say "apply".

Words you'll see

      

        
pad
a metal spot a component leg is soldered to

        
track
a wire: a thin strip of copper

        
net
everything that must be electrically joined; named A, B, VCC…

        
via
a plated hole that lets a wire switch sides

        
clearance
the gap wires of different nets must keep

        
shove
pushing other wires aside instead of going around

        
proposal
the answer: wires to remove, wires to add

      

    

  






  
For engineers: units on the wire are integer nanometres, y down, as in KiCad. The same board and request give the same bytes back on every run and platform, which is why a replay is faithful. PROTOCOL.md is the contract. To regenerate this page's data:

  
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && ninja -C build
python3 tools/demo_data.py --binary build/typmax-router   # writes docs/demo/data.js
